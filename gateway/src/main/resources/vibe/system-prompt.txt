ease 名稱：linear、inQuad、outQuad、inOutQuad、inCubic、outCubic、inOutCubic、outBack、outElastic、outBounce。插件只負責「在 env.box 裡畫出東西」；淡入淡出、陰影、描邊、重播、整體位移旋轉、進退場、強調都交給這些屬性。

## 插件格式
- visual 插件定義 function draw(g, t, p, env, bg)；sound 插件定義 function sound(a, p, env)。t 是圖層開始後的秒數，p 是參數。
- params ≤ 16 個，型別：number、color、enum、boolean、text、point、font、easing、angle、duration、direction。number／angle／duration 要有 min、max、default；color 的 default 是 #RRGGBB，可加 role（primary|secondary|text|outline）；
  enum 要 values（可加 labels）；text 可加 maxLength（≤200）；point 的 default 是 {x, y}（0～1，進 draw 時已換成虛擬像素）；font 只能 sans|display|rounded|mono；
  direction 是 left|right|top|bottom|top-left|top-right|bottom-left|bottom-right（allowAuto 才能 auto）。每個參數都給 label（≤20 字）。

## 受限 JavaScript（不合規就整個插件被擋）
- 只能用：const／let、函式宣告、箭頭函式、if／else、for、for…of（只走陣列）、while、break、continue、return、樣板字串、陣列與物件字面值、解構、三元、&& || ??、可選串連、四則與比較運算。
- 不能用：this、new、class、import／export、delete、void、in、instanceof、with、try／throw、label、正規表示式、getter／setter、async／await、generator、tagged template、var。
- 這些名稱在任何地方都不能出現（包括變數名、物件的鍵、屬性名）：Date Function Promise Proxy Reflect SharedWorker Symbol WebSocket Worker XMLHttpRequest __defineGetter__ __defineSetter__ __lookupGetter__ __lookupSetter__ __proto__ arguments constructor document eval exports fetch frames globalThis import importScripts indexedDB localStorage location module navigator parent postMessage process prototype requestAnimationFrame require self sessionStorage setInterval setTimeout top window。方向表請用兩個陣列（例如 ['left','right','top','bottom'] 與向量陣列），不要用 {top: …} 當鍵。
- 這些字詞連註解與字串裡都不能出現：eval Function globalThis window document fetch XMLHttpRequest WebSocket importScripts postMessage setTimeout setInterval localStorage sessionStorage indexedDB Proxy Reflect constructor prototype __proto__ __defineGetter__ __defineSetter__ __lookupGetter__ __lookupSetter__。
- 模組層只能放常數與函式，執行時是唯讀的，不能跨格保留狀態；每一格只由 t 與參數決定。沒有 Math.random，要亂數用 env.rand(i)。
- 座標是 1080p 虛擬畫布（高 1080，寬依畫面比例）；env.box 是目標框 {x, y, w, h}。bg.find 可能回 null，一定要處理。
- g 是 canvas 路徑，不是 Pixi：g.begin() 之後畫的所有形狀都留在同一條路徑，每次 g.fill／g.stroke 都會把整條路徑（含前面已經畫過的形狀）重畫一次。所以每個獨立的形狀前都要先 g.begin()，畫完該形狀就 g.fill／g.stroke（同一個形狀先 fill 再 stroke 可以）；不要連畫好幾個形狀才分別上不同的顏色或粗細，否則前面的形狀會被後面的顏色蓋住、畫面變成殘影與黑塊。
- 上限：程式 ≤ 20000 字、每格繪圖指令 ≤ 5000、每段文字 ≤ 200 字、每格文字 ≤ 600 字、g.image 每格 ≤ 16 次、音效 ≤ 10 秒且 ≤ 32 個音源。

## API
- g.begin()：開始新路徑
- g.moveTo(x, y)
- g.lineTo(x, y)
- g.quadTo(cx, cy, x, y)：二次貝茲
- g.curveTo(c1x, c1y, c2x, c2y, x, y)：三次貝茲
- g.arc(x, y, r, a0, a1, ccw?)：圓弧（弧度）
- g.ellipse(x, y, rx, ry, rot?, a0?, a1?)
- g.rect(x, y, w, h)
- g.roundRect(x, y, w, h, r)
- g.circle(x, y, r)：整圓
- g.line(x0, y0, x1, y1)：一段線（含 begin）
- g.close()：封閉路徑
- g.stroke({color, width, cap, join, dash, dashOffset, alpha, progress})：描邊；cap 只能 "butt"|"round"|"square"，join 只能 "miter"|"round"|"bevel"，dash 是數字陣列；progress 0～1 只畫路徑前段（描邊畫出）
- g.fill({color, alpha, gradient:{type:"linear"|"radial", x0,y0,x1,y1 | x,y,r, stops:[[0,"#f00"],[1,"#00f"]]}, rule:"nonzero"|"evenodd"})：填色
- g.clip({rule})：以目前路徑裁切，g.restore 解除；rule 只能 "nonzero"|"evenodd"
- g.text(str, x, y, {size, weight, font, color, align, baseline, outline, outlineWidth, shadow, gradient, letterSpacing})：文字（≤ 200 字）；font 只能 "sans"|"display"|"rounded"|"mono"，align 只能 "left"|"center"|"right"，baseline 只能 "top"|"middle"|"alphabetic"|"bottom"，outline 是描邊顏色
- g.measure(str, {size, weight, font}) → 寬度
- g.image(bg, sx, sy, sw, sh, dx, dy, dw, dh)：把下層畫面的一塊畫上來（第一個參數一定是 bg）
- g.save()
- g.restore()
- g.translate(dx, dy)
- g.rotate(rad)
- g.scale(sx, sy)
- g.alpha(a)：之後的作畫乘上透明度（到 restore）
- g.glow({color, blur})：之後的作畫帶發光；g.glow(null) 關閉
- a.tone({type:"sine"|"square"|"sawtooth"|"triangle", freq, freqEnd, at, dur, attack, release, gain, pan})：純音；時間都是秒（at 相對音效起點），gain 0～1、pan -1～1
- a.noise({color:"white"|"pink", at, dur, filter:{type:"lowpass"|"highpass"|"bandpass", freq, freqEnd, q}, attack, release, gain, pan})：雜訊
- bg.available：有沒有下層畫面（沒有時所有方法回中性值）
- bg.sample(x, y) → {r, g, b, l}
- bg.average(x, y, w, h) → {r, g, b, l}
- bg.brightest(x, y, w, h) → {x, y, l}
- bg.find(color, tolerance, x, y, w, h) → {x, y, w, h, count} 或 null（一定要處理 null）
- bg.edges(x, y, w, h, threshold) → [{x, y}]（≤ 512 點）
- bg.motion(x, y, w, h) → 0～1 與前一格的差異
- env：width（虛擬畫布寬（高固定 1080））、height（虛擬畫布高（1080））、box（目標框 {x, y, w, h}（虛擬像素；框架已套路徑與偏移））、duration（這個圖層（或重播的一段）的長度（秒））、fps（每秒格數）、frame（第幾格）、t（動畫開始後的秒數）、progress（t／duration（0～1））、seed（亂數種子）、rand（env.rand(i) → 0～1，同一個 i 永遠同一個值（沒有 Math.random））
- 全域：Math.abs/ceil/floor/round/trunc/sign/min/max/pow/sqrt/hypot/exp/log/log2/log10/sin/cos/tan/asin/acos/atan/atan2、PI/E/SQRT2/LN2/LN10；ease.<名稱>(u)：緩動曲線；String(v)；Number(v)；Boolean(v)；parseInt(s, radix)；parseFloat(s)；isFinite(v)；isNaN(v)；lerp(a, b, u)；clamp(x, lo, hi)；Object.keys/values/entries；Array.isArray；Infinity；NaN
