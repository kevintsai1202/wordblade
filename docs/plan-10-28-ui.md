# 10/28 介面優化與漸進式縮圖（AI 導演之前插入）

開發者 2026-10-28 要求，下一步（AI 導演）前先做。決定：
- 區塊大小：三條分隔線（預覽｜右側面板、上方｜時間軸、軌道標頭寬度），記在這台電腦（localStorage `wordblade.layout`），換專案也沿用；雙擊分隔線回預設（380／300／88）。
- 播放頭：尺規上加可抓的把手、軌道空白處按住也能拖（片段上仍是選取，實作時發現抓整條線會擋住點片段）；拖曳時主預覽跟著跳、旁邊浮出時間碼。
- 播放中介入：**任何移動播放頭的操作都停止播放或倒退**（拖尺規／播放頭、點軌道、點逐字稿、方向鍵），停在新位置。
- 右側面板 6 大類＋子頁籤：Media｜Transcript（Transcript、Caption Style）｜Effects（2D、3D、Zoom、Mask、Sound）｜Inspector｜AI Director｜Export（Export、Publish Kit）。
- 縮圖：三層漸進（匯入時每 10 秒寬 160 → 空檔每 2 秒寬 320 → 每 0.5 秒寬 480），播放、匯出、轉錄、代理檔在跑時暫停；存本機快取。用在：拖曳時先顯示縮圖、時間軸片段影格條、AI 特效／導演取畫面。
