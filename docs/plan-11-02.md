# 11/2 開發計畫：片段變速、AI 導演、SAM 遮罩

依據：`docs/spec.md` §5.20（片段變速）、§5.11（AI 導演）、§5.3（SAM 遮罩）、§8 時程。10/28 提前做，依序做、每項做完再開下一項。

**順序調整（開發者 2026-10-28）**：先做 ③ SAM 遮罩、再做 ② AI 導演——導演的六種建議裡只有「遮隱私」要靠 SAM，其餘（剪、放大、Vibe 特效、用說的運鏡、改字）都已經有；先做 SAM，導演做完時六種建議都能直接採用。AI 導演的決定：影像照規格送 480p、每秒 2 格、無聲影片分段上傳；「加特效」採用時才跑 Vibe。

## 任務

| # | 任務 | 驗收 |
| --- | --- | --- |
| ① | **片段變速（P1-6）**：`setClipSpeed`（0.25～4 倍；同一支素材、同位置同範圍的連動片段——通常是 A1 對白——一起變速）；V1 片段長度改變時 V1 重排，其他未鎖定軌道上「在它原本結束點之後開始」的片段、特效、時間軸定位點一起平移同樣距離，跨在中間的（例如配樂）不剪不動（開發者 2026-10-28 選定）；局部放大用素材時間記，不必動；Inspector 選到片段時顯示片段屬性（倍數按鈕＋自訂）；預覽 `playbackRate`＋`preservesPitch`、匯出 WSOLA 已有 | Vitest（長度、連動、平移規則、鎖定軌、夾住倍數、復原）＋e2e（2 倍後時間軸變短、匯出長度減半且 440 Hz 不變調——補上 plan-10-31 ⑥ 的聽感驗證） |
| ② | AI 導演（P1-1，§5.11）：Spark 逐段＋Wonder 統籌，工具含 proposeZoom（接 `zoomFromRange`） | 先讀規格、確認範圍再開工 |
| ③ | SAM 遮罩（P1-5，§5.3）：遮罩頁籤（任何語言 → Muse Spark 轉英文名詞片語）、選範圍或整個片段＋同意說明；剪出寬 ≤ 1280、每秒 10 格、無聲片段（換鏡頭處切段）；閘道 `/v1/sam`（Files API 一小時到期 → SAM 3.1 追蹤 → SSE 逐格 → 刪檔）；遮罩屬於素材、物件清單（開關、馬賽克／模糊／純色、強度）；合成器 shader 預覽與匯出共用 | 先用一次真實呼叫確認編碼與費用；閘道單元測試＋Vitest＋e2e（假閘道）＋實機 |
