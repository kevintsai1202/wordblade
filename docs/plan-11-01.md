# 11/1 開發計畫：逐字稿與字幕（改字即剪、字幕燒錄、逐字高亮、去贅詞＋清除無聲）

依據：`docs/spec.md` §4（字幕＝詞＋斷句規則＋CaptionBreak、改字的時間重新分配）、§5.1（改字即剪）、§5.2（斷句規則）、§5.4（字幕畫在合成器最上層）、§5.16（一鍵去贅詞）、§5.16b（清除無聲片段）、§5.18（逐字高亮字幕）。10/28 提前做，四項都靠 ASR 的詞級時間，一起開發、一起測。
開發者 2026-10-28 決定：
- **字幕自己用 Canvas 2D 畫**（取代 spec 原訂的 JASSUB／libass）：預覽與匯出同一段程式畫進合成器最上層，三種樣式＋Karaoke 完全可控、好測，沒有 WASM 整合風險；不支援任意 ASS 特效（用不到）。
- **字型隨程式打包**：英文 Inter、中文 Noto Sans TC（OFL），預覽與匯出一致；中文字型分塊，用到的字才載入。

## 任務

| # | 任務 | 驗收 |
| --- | --- | --- |
| ① | **逐字稿面板＋改字即剪**：逐字稿頁籤逐字顯示（依字幕分段），播放到的字高亮；點字跳播放頭、Shift 點選一段、Delete 剪掉（`cutWords`，V1 漣漪＋§4 跨軌規則）；雙擊改字（新編輯 `editWords`：換掉連續幾個詞，字數變了就在原本的總時間內依字數重新分配，指到舊詞的斷點刪掉） | Vitest（editWords）＋e2e（選字刪除、改字、復原） |
| ② | **字幕燒錄**：`captionLayout`（純函式：字幕 → 每行每詞的位置，量字用注入的 measure）＋`drawCaption`（Canvas 2D）；預覽改成畫進合成器（取代 HTML 疊加），匯出也畫；`Project.captionStyle`（樣式：描邊／底色塊／陰影、大小、位置）＋字幕樣式頁籤（`setCaptionStyle` 編輯）；字型 Inter＋Noto Sans TC（`document.fonts.load` 依字幕文字載入，匯出前全部載好） | Vitest（排版）＋e2e（預覽與匯出的 MP4 都有字幕像素、換樣式） |
| ③ | **逐字高亮（Karaoke）**：樣式加 karaoke（off／填色／放大／底色）；講到的詞依詞級時間標出（填色模式已講過的也上色） | Vitest（目前詞）＋e2e（同一段字幕兩個時間點高亮位置不同） |
| ④ | **一鍵去贅詞＋清除無聲片段**：`findFillers`（um、uh、erm、ah、hmm、呃、嗯、欸；清單可改）、`findSilences`（包絡低於 0.01、持續 ≥ 1 秒，前後各留 0.15 秒、不切到詞）→ 時間軸範圍；共用確認清單（勾選、試聽、Remove selected）→ 從後往前 `rippleDelete`，一筆編輯、一次 Ctrl+Z 復原 | Vitest（兩個 find、合併重疊、從後往前）＋e2e（清單、全部移除、復原）＋實機（FOSDEM 片段：真人的 um／uh） |

順序：② 的排版與畫（底層，③ 接在上面）→ ① 面板與改字 → ③ → ④ → 實機與收尾。
